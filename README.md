HabitaMadrid
Sistema de recomendación de municipios de la Comunidad de Madrid basado en:

Precio de alquiler
Transporte público
Calidad del aire
Tecnologías
Python
Streamlit
Pandas
Dataset
Los datos se encuentran en:

data/habitamadrid_dataset_final.csv

Objetivo
Permitir que cada usuario ajuste la importancia de cada factor y obtener recomendaciones personalizadas.
